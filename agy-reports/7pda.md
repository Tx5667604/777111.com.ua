# SEO-аудит и проверка инфраструктуры: 7pda.com

## Индексация
По результатам проверки поисковой выдачи (через Bing / альтернативные поисковики) найдено приблизительно 51 проиндексированная страница. Домен присутствует в индексе и доступен для поиска.

## robots/sitemap
- **robots.txt**: Файл доступен (HTTP 200) и корректен. Открыт доступ для всех ботов (`User-agent: *`, `Allow: /`), закрыт раздел администратора (`Disallow: /admin`). Присутствует корректная директива `Sitemap: https://7pda.com/sitemap.xml`.
- **sitemap.xml**: Возвращает HTTP 200, формат XML валиден. Файл является индексом (Sitemap Index) и содержит 3 вложенных карты (sitemap-static.xml, sitemap-1.xml, sitemap-instructions-1.xml).

## Канонические URL
Выборка из 5 URL страниц (например, `/catalog`, `/masters`, `/parts`):
- **HTTP статус**: Все страницы отдают 200 OK.
- **Канонические ссылки**: Присутствуют на всех страницах и корректно указывают сами на себя (self-referencing).
- **noindex**: Тег `noindex` отсутствует, страницы открыты для индексации.
- **Теги Title и H1**: Присутствуют, заполнены релевантным текстом и уникальны для каждой проверенной страницы.

## Safe Browsing
Проверка через Google Transparency Report показывает статус "Безопасно" (Safe). Домен не числится в списках фишинга, вредоносного ПО или иных угроз.

## Туннель/инфраструктура
Было проверено состояние субдоменов `forum.7pda.com`, `www.7pda.com`, `api.7pda.com`, `app.7pda.com` и `m.7pda.com`:
- **www.7pda.com** и основной домен функционируют штатно и проксируются через Cloudflare.
- **Мертвые хосты**: Субдомены `forum.7pda.com`, `api.7pda.com`, `app.7pda.com` и `m.7pda.com` не работают и возвращают ошибку **530 / Error 1016 (Origin DNS error)** от Cloudflare. Это подтверждает, что коннектор Cloudflare Tunnel `7pda-forum` остановлен или отсутствует правильная CNAME-запись, направляющая на `.cfargotunnel.com`.

## Доступ Googlebot
Проведена проверка доступности сайта с User-Agent `Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)`:
- Главная страница (`/`) и `sitemap.xml` возвращают HTTP 200.
- Блокировок со стороны WAF (403 Forbidden) или капчи (Challenge) для Googlebot не обнаружено.

## Проблемы
1. **Недоступность форума и API**: Cloudflare Tunnel для `forum.7pda.com` лежит (ошибка 530 / 1016), сервис не может установить соединение с localhost:3000. Аналогичная проблема наблюдается у субдоменов `api`, `app`, `m`.

## Рекомендации
1. **Восстановление туннеля**: Запустить и авторизовать cloudflared коннектор на сервере, где работает localhost:3000, проверить статус туннеля `7pda-forum` в дашборде Zero Trust. Убедиться, что CNAME записи субдоменов направлены на корректный UUID туннеля.
2. **SEO-настройки**: Текущие конфигурации robots.txt, sitemap.xml, канонических тегов и прав доступа для Googlebot настроены безупречно — изменения не требуются.

---
**Краткий вывод:**
Базовые SEO-параметры (robots, sitemap, canonical, доступность для Googlebot) настроены корректно и функционируют без сбоев. Проблем с безопасностью (Safe Browsing) не обнаружено. Однако, инфраструктурная часть форума и API полностью недоступна из-за нерабочего Cloudflare Tunnel (ошибка 530/1016). Для восстановления работы поддоменов требуется перезапуск коннектора на хосте с localhost:3000.
